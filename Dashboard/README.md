# Admin Dashboard Clone

## Overview

This project is a responsive **Admin Dashboard UI** built using **HTML5** and **CSS3**. It recreates the look and feel of a modern admin panel inspired by the AdminLTE template. The dashboard contains a navigation bar, sidebar, dashboard cards, charts, and a footer with a clean dark theme.

The project focuses on front-end layout design, CSS Grid, Flexbox, and responsive styling without using JavaScript.

---

## Features

* Fixed sidebar navigation
* Top navigation bar with icons and notifications
* Dashboard statistic cards
* Sales and analytics section
* Dark theme UI
* Footer section
* Bootstrap Icons integration
* Remix Icons support
* Clean and organized CSS structure

## How to Run

1. Download or clone the project.
2. Keep all project files inside the same folder.
3. Ensure the following files exist:

   * `dashboard.html`
   * `dashboard.css`
   * `img1.png`
   * `img2.png`
   * `img3.png`
4. Open `dashboard.html` in any modern web browser.

No installation or server is required.
